# DISC UP 2 — Reach Mission

ディスクアップ2の全222リーチ目ミッションと、21停止位置・105制御パターンを、PCでもスマートフォンでも見やすく確認するためのローカルWebアプリです。

公開版：<https://nakanoryunosuke.github.io/discup2/>

## 起動

Node.js 18以降で、次を実行します。

    npm run dev

ブラウザで <http://127.0.0.1:8787> を開いてください。外部パッケージのインストールは不要です。

- ミッション管理：<http://127.0.0.1:8787/index.html>
- 制御・スベリ対応表：<http://127.0.0.1:8787/table.html>

## 主な機能

- 全222件のリーチ目画像をカード表示
- 実際の図柄画像を使った連続リールを上下に動かし、左・中・右の停止形から対応するリーチ目を検索
- 有効な停止形を初期表示し、マウスホイールは1ノッチで1コマ、タッチスワイプは指の移動量に追従して回転
- 上下キーとプルダウンによる直接選択にも対応
- 1リールだけの部分検索に対応し、ミッション画像の「Any」はワイルドカードとして判定
- 番号・停止位置・コメントを横断検索
- 達成状態、ランク、左リール位置、打ち方による複合絞り込み
- 番号、難易度、未達成優先、候補数での並び替え
- ランク別を含む進捗表示
- お気に入りと未達成からのランダム選択
- 詳細モーダルと前後移動
- 達成状態のブラウザ内自動保存
- JSONによる保存データの書き出し・読み込み
- 下段に押す図柄を連続リールで選べる、左リール21停止位置 × 5スベリのインタラクティブ制御表
- 「停止位置 → スベリ → 対応役」の段階表示
- 制御結果の左リール停止形に対応するリーチ目ミッション画像を同じ画面に一覧表示
- ミッション画面の達成状態を同期し、達成済みを表示・非表示に切り替え
- 成立役から105パターンを横断する逆引き検索
- 1確・停止しない制御の色分け

## 確認

    npm run check

ミッション数、番号の重複・欠落、ランク、全画像、JavaScript構文を検証します。

## データ更新

参照元の公開ページからミッション情報と画像を再取得する場合は、次を実行します。

    npm run sync

停止形インデックスだけを画像から再生成する場合は、Python 3、Pillow、NumPyを用意して次を実行します。

    npm run sync:patterns

ミッション情報・画像は [P Tool](https://p.datu.work/model/discup2/mission.html)、制御情報・画像は [パチスロのある日常](https://mokkun7.com/enjoy/discup2-table/) を参照しています。本アプリは非公式のローカル再構成です。
